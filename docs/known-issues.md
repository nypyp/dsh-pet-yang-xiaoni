# 已知问题与「不是 bug」的行为

本文件记录核实过的问题、根因、修法，以及**由 App 侧决定、宠物包改不了**的行为。
新问题请按 `.github/ISSUE_TEMPLATE/bug_report.yml` 提，附上截图/录屏、App 版本和宠物包版本（`git describe`）。

## 1. 干活时「头和身体快分离」——已修复（v0.1.1）

**现象**：`working`（工具运行/回复流）的某些帧里，脖子处有一条深色横线，头看起来像浮在身体上；
`roam-hop`、`sweeping` 也有同样的帧。

**根因**：`draw_cat` 里身体顶部和头部底边分别独立取整。半像素偏移（例如 `working` 的 `lift=-0.5`）
在 Python 的 `round()`（银行家舍入）下会得到 `31.5 → 32`、`20.5 → 20`，于是头部底边在第 46 行、
身体顶部从第 48 行开始，中间空出第 47 行——描边把这个空行涂成深色，看起来就是「断头」。

**修法**：身体顶部夹到头部底边（`top = min(top, hy + 11)`）；加了逐帧回归测试
`test_head_and_body_stay_connected_on_every_frame`（渲染每帧、去掉描边和阴影后，毛色像素必须是一个连通块）。

## 2. 「彩蛋」很难看到——部分属实，已改善

**核实**：

- `bonus` 只在**进入状态时**抽一次（`pet_stage.dart` 的 `_onState` → `_startVariant`），播一遍就回状态动画，不是循环。
- `attention` 的触发条件是一整轮结束后 1.5 秒内没有新轮次（`pet_mood.dart` 的状态表）。
  连续长任务里这一轮一直没结束，自然看不到「注意 / 爱心爆发」。
- 待机小剧场只在真正空闲时按 40–280 秒随机插播。

**结论**：README 原来只列了动画，没写触发条件，容易让人以为「随便就能看到」。v0.1.1 起：

- README 加了「什么时候会出现哪个动作」对照表；
- 给最常看到的两个状态加了彩蛋变体：`thinking2`（25%）、`working2`（20%）；
- `thinking` 从 2.4 秒拉长到 3.6 秒、`working` 到 3.2 秒，各自加了一个「抬头看屏幕 / 眨眼」的节拍，
  长任务里不会一直定格同一帧。

## 3. 「恼了」很难触发、触发后一闪而过——属实，但阈值在 App 侧

**核实**（`app/lib/ui/pets/pet_stage.dart`，符号名稳定，行号可能随版本变化）：

```dart
static const tickleTaps  = 3;                                  // 1.1 秒内 3 下 → 挠痒
static const tickleWithin = Duration(milliseconds: 1100);       // 滑动窗口
static const annoyedTaps = 6;                                  // 1.1 秒内 6 下 → 恼了
```

`_onTapUp` 每次点击先剔除 1.1 秒以前的记录，再判断：

- `>= annoyedTaps` 且包里有 `annoyed` → 清空计数、重震动、播 `annoyed`；
- `>= tickleTaps` → 播 `tickle`（继续点会续时长）；
- 其它 → 按左右播 `tapLeft` / `tapRight`。

所以「1.1 秒内 6 下」≈ 每秒 5.5 下，小目标上本来就难；而**任何后续点击都会立刻顶掉当前反应**
（`_play` 只有一个 `_reaction` 槽），第 7 下就把「恼了」换掉了，于是看起来「一瞬间就没了」。

**宠物包能做的**（v0.1.1 已做）：

- `react-annoyed` 从 0.9 秒拉到 1.8 秒（30 帧 × 60 ms），第一帧就是炸毛表情 + 感叹号，
  即使被后续点击打断，也能看到「生气过」；
- 加了耳侧蒸汽、尾巴甩动，生气更明显。

**宠物包改不了的**：阈值（3/6 下、1.1 秒）、连点覆盖反应、点击命中的判定，都在 App 侧。
想调整只能给 dsh-go 上游提 issue。

**绕法**：用两根手指交替点（更容易在 1.1 秒内凑够 6 下）；把宠物调成「大/自定义」让命中区更大；
点到第 6 下后先停手，等 1.8 秒生气的动画播完。

## 4. 动图里的漂浮白块——已修复（v0.1.5）

**现象**：README 里 `working` / `working2` / `thinking2` 的 GIF 中，猫身边偶尔出现一块白色小方块/爪子，
和身体不相连，像渲染错误。

**根因**：拍红点、拨毛线球、够飞蛾时单独画了「爪子」道具，但这个宠物没有手臂美术，爪子悬空后
被描边包了一圈，看起来就是一块漂浮的白块。

**修法**：去掉漂浮爪子，改成整只身体的反应（压低、甩尾、扑跳、落地起灰、跳起来够），并把道具加大加亮。
`make gallery` 重新生成全部 GIF。

## 5. 悬浮窗和聊天页的差异（不是 bug）

- 悬浮窗空闲 10 秒会变淡到 60% 并暂停动画，碰一下恢复；
- 悬浮窗不游走，只在原地播动作；
- 网页模式的聊天页里没有原生宠物（那是 dsh-pet 插件的事），但悬浮窗在两种模式下都能用。
